# Algoritmos (Manzano) – Listas de exercícios em Java

Listas 01 a 12 e exercícios extras, cada lista em uma pasta (`lista01` a `lista12`). Os exercícios "a, b, c..." viraram `L01A`, `L01B` etc.
Temas: entrada e saída, decisões, repetições (enquanto, repita, para), vetores, matrizes, registros com menu, procedimentos e funções.
As respostas teóricas da Lista 01 estão em `lista01/respostas_teoricas.md`.

## Como executar
    javac -encoding UTF-8 -d out $(find . -name "*.java")
    java -cp out lista03.L03A
