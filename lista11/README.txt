Lista 11 – procedimentos. Cada exercício tem dois algoritmos no mesmo arquivo:
  porValor(...)        -> os parâmetros são copiados; o procedimento só mostra o resultado.
  porReferencia(..., r) -> Java sempre passa por valor, mas ao passar um array/objeto a "cópia da referência"
                           aponta para o mesmo dado; assim o procedimento grava o resultado em r[0] (simula
                           a passagem por referência do Portugol) e o main apresenta.
